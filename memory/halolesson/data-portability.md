# Future data portability and sharing

*(as of 2026-11-05)*

The user wants these after the current base/UI work:
- Export and import their data.
- Share individual skills.
- Share complete subjects, including their lessons/skills.

Keep these future requirements in mind when settling the generated-lesson format and IDs, but do not move them ahead of the current UI phase.

Related: [[halolesson-vision]], [[halolesson-open-questions]]

*(2026-11-06)* User wants the export redesigned: a single JSON file "won't be enough / future proof". Subjects, skills, trackers etc. must each be shareable individually AND together; maybe a zip. To brainstorm after Tracker ships. Tracker export currently rides in ExportSubject (type/level/notes).
