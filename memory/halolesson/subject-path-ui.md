# Subject and skill-path UI direction

*(as of 2026-11-05)*, from user direction and two supplied Duolingo screenshots.

## Subjects page
- A rotating 3D open-book artwork sits in the center, at roughly the same visual scale as a skill-level node.
- Subjects are arranged in a circle/orbit around that central artwork rather than presented only as rectangular cards.
- Clicking a subject triggers a clean animated reveal/transition into that subject's course-like path, even though the course is user-created.
- Each subject contains its own user-defined lessons and skills.

## Subject path
- Skills use chunky circular Duolingo-like level nodes. Different subjects can use different node shapes/symbols to distinguish them.
- Each subject has a customizable **color gradient**, not just one flat color.
- Skills along a path inherit colors from positions along that gradient: early skills sit near one end and later skills progress toward the other end. Level colors can shift over time as the path/progress changes.
- A skill reaches a distinctive **gold level** when the user has perfected everything, matching the gold Duolingo reference screenshot. Gold mastery is a core visual target.
